# WECHAT_PUBLISH.md — 微信小游戏发布指南

> 本指南描述从本工程到微信小游戏提审的完整步骤。其中需要账号权限、AppID、广告位 ID 的步骤**无法自动完成**，需人工操作。

## 一、前置条件

1. 已注册微信小游戏账号（https://mp.weixin.qq.com ），并获得 **AppID**。
2. 已安装 **Cocos Creator 3.8.x**（Dashboard → 安装 3.8 稳定版）。
3. 已安装**微信开发者工具**（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html ）。
4. 微信开发者工具 → 设置 → 安全设置 → 开启「服务端口」（供 Cocos 构建后自动打开）。

## 二、配置 AppID 与广告位

编辑 `assets/scripts/platform/PlatformManager.ts`：

```ts
static WECHAT_APP_ID = 'wx你的AppID';
static WECHAT_REWARDED_AD_UNIT_ID = 'adunit-你的激励视频广告位ID';
```

- 广告位在小游戏后台 → 流量主 → 广告位管理 创建（需满足开通流量主的条件）。
- **未配置时游戏自动降级 Mock 模式**：可正常运行与测试，但不会产生真实收入，且 Mock 广告有明确标识。
- Banner 广告接口已预留（`WeChatAdService.showBanner`），第一版默认关闭；启用前请先确认广告布局不遮挡收纳槽操作区并符合平台规范。

## 三、构建步骤（Cocos Creator）

1. Cocos Creator 打开本工程（见 DEVELOPMENT.md）。
2. 菜单 **项目 → 构建发布**。
3. 新建构建任务：
   - 发布平台：**微信小游戏**
   - AppID：填入你的小游戏 AppID（或使用测试号）
   - 游戏名称：收纳大作战
   - 初始场景：loading
   - 设备方向：Portrait（竖屏）
   - md5 Cache：建议开启
4. 点击**构建**，完成后点击**生成**（生成到 `build/wechatgame`）。
5. 点击**打开微信开发者工具**（或手动用微信开发者工具导入 `build/wechatgame` 目录）。

## 四、微信开发者工具内验证清单

- [ ] 编译无报错，模拟器出现 Loading → 首页
- [ ] 首页音乐播放、开始游戏进入关卡
- [ ] 点击物品进入槽位、三消动画、Combo 提示
- [ ] 遮挡物品点击有反馈但不可拾取；消除后下层解锁
- [ ] 冰冻/锁定物品机制生效（31 关起）
- [ ] 撤回/洗牌/移除/加槽道具真实生效
- [ ] 通关弹窗 → 下一关解锁 → 重新启动游戏进度恢复
- [ ] 失败 → 观看广告复活（真机/模拟器显示真实广告，开发者工具中可能无填充）
- [ ] 每日奖励领取、金币增减正确
- [ ] 真机预览（工具 → 预览）验证触控与音频

## 五、真机测试注意事项

- 首次运行会出现授权弹窗与隐私协议要求：在后台「设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引」中补充声明（本项目仅使用本地存储，不收集个人信息）。
- 音频建议真机实测（WAV 兼容性已按平台支持列表选择）。
- 广告填充需要真机 + 已开通流量主的 AppID。

## 六、提审

1. 微信开发者工具 → 上传 → 填写版本号与备注。
2. 小游戏后台 → 版本管理 → 提交审核。
3. 审核注意：
   - 类目选择「游戏 > 休闲游戏」，需提供软著或承诺函（按平台当前要求）。
   - 确认游戏内无诱导分享、无未经授权素材（本项目素材均为原创生成）。
   - 广告展示位置符合《微信小游戏广告规范》。

## 七、目前是否具备真实广告变现条件

| 条件 | 状态 |
|---|---|
| 微信激励视频广告真实调用实现 | ✅ 已实现（createRewardedVideoAd + 完整生命周期） |
| 广告位 ID 配置入口 | ✅ PlatformManager 静态配置 |
| Mock 降级（无 ID 也能跑） | ✅ |
| 小游戏账号 + 流量主开通 + 广告位创建 | ❌ 需要你人工完成 |
| 真实广告联调验证 | ❌ 需要 AppID + 真机后进行 |

结论：**代码层面具备接入条件；实际变现需完成上表后两项人工步骤。**
