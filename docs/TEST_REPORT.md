## 五之三、收纳槽物品消失 bug（用户反馈，已修复 + 回归覆盖）

**现象**：消除一组后，放入收纳槽的物品不可见。

**根因**：三消时给槽位元素添加了 `.gather` 动画类（`animation: gather ... forwards`，结束帧 `opacity: 0`），
但重建槽位时未清除该类；CSS `forwards` 让该槽位之后放入的所有物品都定格在透明状态。

**修复**：
1. `rebuildSlots()` 重建前清除 `gather/clearing` 临时类；
2. 新物品入槽时清除目标槽位的残留动画类；
3. 三消动画结束后统一清理，双保险。

**回归测试**：`node tools/browser-regression-slot.mjs` — 逐步点击整关解法，每次拾取后校验所有槽位物品
`opacity ≥ 0.9` 且无残留动画类；并验证 4 次消除、结算清空、通关宝箱。修复后 5/5 通过。
（把修复临时回退后该测试能稳定复现：槽位残留 `gather`、物品透明度 0.26 → 证明测试有效。）

## 六、本轮修复的真实缺陷

1. **存档迁移丢档（严重）**：checksum 在迁移后校验，迁移新增字段导致所有 v1 旧档被判损坏 → 改为**迁移前**对原始数据校验。
2. **奖励可能丢失**：宝箱若在开箱前退出会丢失奖励 → 改为通关即结算并持久化，开箱动画只做展示（仍按 rewardId 幂等）。
3. **收藏品与关卡难度不匹配**：原 100 关最大 90 物品、L2 仅 27 物品 → 重排为 L1 12 / L2 45 / L3 54 / L4 66 / L5 75+障碍 / L100 150。
4. **L21 物品数回退**（108→99）→ 修正为单调递增。
5. **首页信息架构**：原首页无收藏入口、无等级、无任务 → 重做（收藏册卡片 + 4 快捷入口 + 玩家卡）。
